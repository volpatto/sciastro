- Initial alpha package for individual and research-group websites using YAML,
  Markdown and BibTeX, with Portuguese/English content and light/dark modes.
- Automatic academic pages, team and alumni grouping, citations, configurable
  icons, composed sections, custom components and classic/modern/LNCC themes.
- CLI scaffolding, content checks and independently installed package tests.
- MkDocs documentation with individual/group tutorials, API reference and a
  dedicated locked Pixi environment.
- Tag-triggered releases with version consistency checks, cross-platform tests,
  npm trusted publishing and documentation deployment tied to the release.

This is an initial alpha. Configuration and extension APIs may change; subsequent
incompatible changes will include migration notes. The content schema is version 1.
